KIE.AI の Suno API を使って、AI 楽曲をバッチ生成するエージェントスキルです。**エンジニアでない方でも、この手順に沿って最初の1曲まで進められる**ように設計されています。生成そのものは AI エージェント（Claude Code / ChatGPT / pi など）が行うので、人の作業はアカウント作成と初期設定だけです。

よくある質問（商用利用・課金・トラブルなど）は **[FAQ.md](FAQ.md)** にまとめています。

🎬 **説明スライド**: [ブラウザーで開く](https://genkoko.github.io/music-kie-suno-skill/s/music-skill-deep-dive) — 全16ページでスキルの全体像を解説（詳細は下部の「説明スライド」セクション）。

## エージェント向けクイックスタート（AI エージェントが読む節）

あなたが AI エージェント（Claude Code / ChatGPT / pi など）で、「Suno で曲を作って」という依頼を受けたなら、この節に沿って実行してください。ユーザーの最初の連絡が「このスキルの GitHub URL をインストールして、KIE.AI の onboarding も進めて」という内容の場合は、まず `npx skills add GenKoKo/music-kie-suno-skill` で導入してから、この節の preflight → onboarding に進みます。ユーザーは多くの場合エンジニアではないため、ターミナル操作はすべてエージェント側で行い、ユーザーには意思決定（承認・課金）だけを頼みます。

1. **実行環境の検出**：`node --version` で Node.js の有無を確認します。**Node.js がある場合、このステップは黙ってスキップします**（インストールの話は切り出さない）。`npx` は Node.js に同梱されているため、Node がなければインストールもスキルの実行もできません。未インストールの場合は、ユーザーの OS を判定してインストールします：macOS → Homebrew があれば `brew install node`、なければ下の Step 3 の一行コマンド（公式 .pkg）をユーザーのターミナルで実行してもらいます（`sudo` のパスワード入力が必要なため、エージェント自身のシェルからは実行できません）；Windows（PowerShell）→ `winget install OpenJS.NodeJS.LTS`。サイトからの入手を希望する場合は、ユーザーの OS・CPU に合う公式インストーラ（macOS：.pkg ユニバーサル版／Windows：x64 の .msi。https://nodejs.org/en/download ）を案内します。インストール後、再確認します。
2. **スキルのインストール**：`npx skills add GenKoKo/music-kie-suno-skill` をエージェント自身が実行します（ユーザーに実行させない）。インストール先はカレントディレクトリの `.agents/skills/music-kie-suno/`（skills.sh の既定動作）
3. **プレフライト**：`.agents/skills/music-kie-suno/` で `node scripts/suno.js credit` を実行します。残高表示・サービス死活確認・更新通知（`UPDATE AVAILABLE` 表示時は What is new の変更メモも一緒に表示 — エージェントが内容を説明し、ユーザーが判断してから `npx skills add GenKoKo/music-kie-suno-skill` で更新）を兼ねます。出力はユーザーにそのまま伝えます。セットアップガイドが表示された場合は、それをそのまま伝えて案内に従います。
4. **初回ユーザーのオンボーディング**：アカウント・API キーが未設定なら、下の Onboarding Step 1–2 を案内します（登録リンクは既定で日本語ロケール `https://kie.ai/ja?ref=dd95e71edb49afb16467a8523cbf31d8` を使います）。キーの設定は OS とシェルを判定してエージェントが代行します：macOS / Linux → `~/.zshrc` などへの恒久 `export`；Windows → `setx`（恒久）または `$env:`（現在のセッションのみ）。ユーザーがキーをチャットに貼った場合は、返信にキーを表示せず、チャットを経由した旨を一度だけ伝えます（あとで https://kie.ai/ja/api-key でキーを再作成すれば無効化できます）。
5. **生成**：自然言語の依頼（例：「Suno で BGM を 2 曲」）を受けたら、残高確認 → 生成プランの提示 → ユーザーの明示的な承認（承認前にクレジットは一切消費しない）→ バッチ生成 → 進捗報告とファイルの保存、の順で進めます。ユーザーが曲数で指定した場合は、**1 リクエスト＝2 曲**（同一プランの 2 バージョン）であるため、リクエスト数に換算して（例：「3 曲」→ 2 リクエスト＝4 曲）プラン作成前に必ず確認します。完全な操作契約は `SKILL.md` にあるため、初回生成前に必ず読んでください。

## はじめての方へ（Onboarding）

> 💡 **言語切替**：**https://kie.ai/ja** を開けば日本語表示になります（未ログインでもOK）。ランディングページ右上のアイコン、ログイン後は左サイドバー最下部の「日本語」ボタンからも切替できます（English / 日本語）。ただしドキュメントを含め多くのコンテンツは英語中心の表示です。

### Step 1 — アカウント登録

1. 次のリンクから KIE.AI にアクセスして登録します：**https://kie.ai/ja?ref=dd95e71edb49afb16467a8523cbf31d8**
2. パスワードの設定は不要です。**Google または Microsoft アカウントでそのまま登録・ログイン（SSO）**できます（メール＋パスワードのフォームは既存アカウントのログイン用）。いずれかでサインインすると登録完了です。

> **紹介リンクについて**：上記は作者（Ko @ AIxBGM自動販売機）の紹介リンクです。このリンク経由で登録し、**初月に課金された場合のみ**作者に少額の commission が入る仕組みです。リンクを使わなくても、サービスの機能・料金は一切変わりません。

### Step 2 — APIキーの取得（カード不要）

1. ログインした状態で **https://kie.ai/ja/api-key** を開きます（日本語表示では「**APIキー**」というメニュー名です）。
2. アカウント作成直後から「Default」APIキーが既に存在します。**その行に表示されているのがAPIキー本体**で、ワンクリックでコピーできます。そのままコピーすればOKです（「新しいキーを作成」は任意：複数キーやIP制限を使いたい場合のみ）。
3. キーは**他人に絶対に見せないでください**。これがあなたの財布の鍵です。Step 3 で使います。

### Step 3 — Node.js とキーの設定

Node.js がない場合はインストールします：

```bash
# macOS（Homebrew がある場合）
brew install node
```

```bash
# macOS（Homebrew なしでも一行でOK：公式 .pkg をダウンロードしてインストール）
# 実行すると Mac のパスワードを求められます（入力中は表示されません）。ターミナルに貼り付けて実行
cd /tmp && curl -fsSL https://nodejs.org/dist/latest-v24.x/ | grep -o 'node-v[0-9.]*\.pkg' | head -1 | xargs -I{} curl -fsSL -o node.pkg "https://nodejs.org/dist/latest-v24.x/{}" && sudo installer -pkg node.pkg -target /
```

**サイトからの入手を希望する場合**：https://nodejs.org/en/download の LTS から、macOS は「**macOS Installer (.pkg)**」（Apple Silicon / Intel 両対応のユニバーサル版）を、Windows は「**Windows Installer (.msi)**」（x64）をダウンロードして実行します。どれを選べばいいか分からない場合は、エージェントがあなたの OS と CPU を判定して教えます。

```bash
# Windows (PowerShell)
winget install OpenJS.NodeJS.LTS
```

> 🔐 **パスワード入力が必要なのは、この Node.js のインストール時だけ**です（macOS のインストーラ実行、Windows の UAC 確認）。APIキーの設定や音楽生成にパスワードは不要です。

APIキーの設定方法は「エージェントにおまかせ」と「手動設定」の2つあります。特徴を比べて、自分に合う方を選んでください：

| 方法                   | 手間                               | 向いている人                               | 注意点                                                                       |
| ---------------------- | ---------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------- |
| エージェントにおまかせ | 最小（貼り付けて「設定して」だけ） | すぐ試したい方・ターミナル操作に不慣れな方 | キーがチャット経由でやり取りされます（後からキーを作り直せば無効化できます） |
| 手動設定               | コマンド1行を自分で実行            | キーをチャットに渡したくない方             | 自分のOS・シェルに合うコマンドを選ぶ必要があります                           |

**かんたん設定（エージェントにおまかせ）**：コピーしたAPIキーをそのままエージェントに貼り付けて「設定して」と言えば、環境変数の設定と残高確認まで代行します。エージェントはあなたのOS・シェルを判定して、該当する手順だけを実行します。キーは返信に表示せず、シェルの設定ファイル以外には保存しません。

**手動設定（自分でコマンドを実行）**：macOSは「ターミナル」アプリ、Windowsは「PowerShell」を開きます。自分の環境に合うコマンドを1行実行してください（どれか分からない場合は、エージェントに「手動設定のコマンドを教えて」と聞けば、あなたのOSとシェルに合わせた1行を提示します）：

```bash
# macOS / Linux（~/.zshrc などに追記後、ターミナル再起動）
export KIE_AI_API_KEY=さっきコピーしたキー
```

```bash
# Windows（PowerShell・恒久設定。実行後ターミナル再起動）
setx KIE_AI_API_KEY さっきコピーしたキー
```

```powershell
# Windows（PowerShell・現在のターミナルだけ有効）
$env:KIE_AI_API_KEY = "さっきコピーしたキー"
```

なお、キーをチャット経由で渡したくない場合は手動設定をどうぞ。いずれの方法でも、後から https://kie.ai/ja/api-key でキーを作り直すことができます。

**設定の確認**：ターミナルを開き直して `node scripts/suno.js credit` を実行し、残高が表示されれば設定完了です（エージェントにおまかせの場合はこの確認も自動で行われます）。

### Step 4 — 最初の1曲を生成（まずは無料クレジットで試せる場合も）

エージェントにこう依頼するだけです：

> 「Sunoで6分の作業用BGMを1曲作って」

エージェントが残高確認 → 生成プランの提示 → あなたの承認 → 生成 → ダウンロードまで全部案内します。承認前には一切クレジットを消費しません。

**比較におすすめ（2モード）**：Instrumental に加えて、ボーカル入りも1リクエスト生成してみてください（例：「同じ雰囲気で、日本語の歌詞をつけた曲も1曲」）。2リクエスト＝4曲・約24クレジットで、歌詞あり／なしの違いと AI ボーカルの質感を一度で確認できます。歌詞はエージェントが提案します（聴きたい人と場面から主題を組み立てます）。

**まず無料で試せる場合があります**：新規ユーザーへのテスト用80無料クレジット（約6リクエスト＝12曲分）は公式FAQによる**主張**であり、実際の付与状況が優先します（2026-09-11時点・付与条件は変更される場合があります）。付与されていれば、この時点で課金なしに試せます。付与されていない場合は、先に Step 5 でチャージしてください。

初回の流れと目安：

- 承認すると生成が始まり、進捗は約1分ごとに表で報告されます
- 生成には1リクエストあたり約3〜4分かかります（V6・360秒曲の実測：171〜215秒、2026-09-12。旧V5_5より長めです）
- 1リクエストで2曲できあがるので、気に入った方を使ってください
- 完成した mp3 は `output_music_kie_suno/<日付>/` フォルダに保存され、場所は案内されます
- プラットフォーム上の生成音源は**約 14 日**で削除されます。ローカルに保存されたファイルが唯一の永続コピーです。必要な曲は早めにバックアップを（保持期間は最新の公式情報が優先）
- 気に入らない場合は「もう一度」で再生成できます（1リクエスト約12クレジット）

### Step 5 — クレジットカード登録とチャージ（必要になったら）

無料クレジットを使い切った後、または残高不足の案内が出たときに行います：

1. ログイン後、ダッシュボードの **Billing / Top-up** ページを開きます（日本語表示では「**請求情報**」というメニュー名です）。
2. クレジットカードを登録します（**Apple Pay** も使えます。カード番号を相手先に知られずに支払えるため安心です）。
3. クレジットをチャージします。チャージ料金の目安（**2026-09-11 時点**・詳細は必ず公式 Billing ページの表記が優先）：

   - **$5 = 1,000 クレジット**
   - **$50 = 10,000 クレジット**
   - **$500 以上**のチャージにはお得なボーナスクレジットが付与されます

   消費の目安：**1リクエスト = 約12クレジット**。クレジットに有効期限はありません（最新の条件は公式 Billing ページの表記が優先）。

## 使い方（通常フロー）

「Sunoで作業用BGMを3曲生成して」「もっと実験的な音色で5曲」のように自然に依頼すると、エージェントが：

1. クレジット残高を確認
2. 生成プラン `plan.md` を作成して提示（曲数・スタイル・見積もりクレジット・現在残高）
3. 承認後にバッチ生成を開始
4. 1分ごとに進捗テーブルを報告（1リクエストあたり約3〜4分）
5. 完了後、楽曲ファイルとレポートを案内

## 呼び出しフレーズ集（コピーして使えます）

| 目的             | フレーズ                                                |
| ---------------- | ------------------------------------------------------- |
| 最初の1曲        | Sunoで6分の作業用BGMを1曲作って                         |
| 比較生成（推薦）  | 同じスタイルで、ボーカル入りとなしを1曲ずつ生成して比べる            |
| 雰囲気を指定     | 落ち着いた夜のピアノジャズのBGMを3曲                    |
| 好きな楽器で     | アコースティックギターのフォーク調で5曲、ボーカルなしで |

| 実験的に         | 同じ雰囲気でもっと実験的なアレンジで5曲                 |
| 多めにまとめて   | 勉強用BGMを10曲、雰囲気はおまかせ                       |

> ※ 曲の長さの指定は V6（既定）で反映されます。V6_MINI は長さを無視することがあります。

「作りたいシーン」「雰囲気」「曲数」が伝わればOKです。曖昧な依頼でも大丈夫 — エージェントが3つの質問（シーン／気分／楽器とテンポ）で絞り込みます。迷った場面ではa〜eの選択肢を提示してくれるので、一文字でも答えられます（大文字でもOK）。「前回と同じスタイルで」も選べます。生成プランを提示して承認を待ちます。曲数・長さ・見積もりクレジットは必ず承認前に確認されます。

## 出力と命名規則

- 出力先：プロジェクト内では `<プロジェクト>/output_music_kie_suno/<YYMMDD>/`、プロジェクト外では `~/Documents/output_music_kie_suno/<YYMMDD>/`
- 保存先は初回に選べます。変更する場合はエージェントに「保存先を ○○ にして」と伝えるだけで設定されます（環境変数 `OUTPUT_DIR_MUSIC_KIE_SUNO` に保存。解除すればデフォルトに戻ります）
- 既定のモデルは **V6**（聴き比べによる選定）。バリエーションはスタイル重みで調整します（「もっと実験的に」と伝えればOK）。`V6_WILD` はザラつき音が目立ち非推奨、`V6_MINI` は軽量ですが指定長を無視することがあります。
- ファイル名：`suno-<model>-<YYMMDD>-<HHMMSS>-<連番>-<曲名>.mp3`（例：1曲目 `suno-V6-260910-164913-001-Quiet_Hours_A1.mp3`。2曲目はエージェントが付けた別題名で保存されます（例：`...-002-Quiet_Hours_A2.mp3`）。別題名がない場合は `_v2` 接尾辞が付きます）
- 1リクエストにつき2曲生成され、両方ダウンロードされます
- 統計は `log.jsonl` に蓄積されます

## 安全性について

このスキルは、次の方針で安全性を保っています：

- **コードは全面公開（MIT License）** — 動作のすべてが公開され、誰でも監査できます。外部ライブラリにほぼ依存しない Node.js 標準機能だけの最小構成です
- **APIキーは環境変数のみ** — キーがコードに埋め込まれることはなく、プラン・レポート・ステータスファイルにも書き込まれません。エージェントによる設定支援でも、キーをチャットに表示し直すことはありません
- **同梱の自己点検スクリプト** — `scripts/self-audit.sh` が、キーの直埋め・許可リスト外の接続先・危険な処理がないかを自動でチェックします
- **課金は承認後のみ** — 残高と見積りの確認なしに生成を開始せず、失敗したリクエストは課金されません
