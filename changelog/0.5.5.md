# 0.5.5 — 2026-09-15 (track numbering beyond 999)

Fix release — the daily track counter no longer silently resets at 1,000. Generation behavior unchanged. Update with `npx skills add GenKoKo/music-kie-suno-skill`.

## Fixed

- Track filenames above 999 tracks in a single day: the numbering scan only recognized 3-digit sequences, so from track 1,000 onward every download silently overwrote the same file (`-1000-<title>.mp3`). The scan now accepts any digit length and numbering continues 999 → 1000 → 1001 … without collisions
- Verified: a directory containing 998/999/1000/1001 tracks returns the next free number (1002)
