# 0.5.2 — 2026-09-13 (docs, safety copy, report rework, interaction guidance, agent naming)

Docs-and-UX release — generation behavior unchanged, but run output files evolve: `report.md` is reworked (Japanese track-level receipt) and `progress.md` is removed (mid-run visibility via `node scripts/suno.js status`; `status.json` is written continuously). Update with `npx skills add GenKoKo/music-kie-suno-skill`.

## Added

- READMEs (ja/en): Security section — full source disclosure (MIT), env-var-only API key handling, bundled self-audit script, approval-gated spending
- READMEs: password scope note — the only password prompt is the Node.js install (macOS .pkg installer / Windows UAC); key setup and generation never require it
- READMEs: interaction note — clarifying questions come with 3–5 labeled options (a/b/c…, case-insensitive), so one-letter answers work
- SKILL.md: Step 0 no-Node error-string triggers (zsh/bash `command not found: npx`, Windows cmd/PowerShell variants) so agents recognize a missing Node runtime without OS hints
- SKILL.md: Music design and planning quick reference (scene/mood/instrument/tempo prompting guidance)
- SKILL.md: interaction guidance — clarifying questions present 3–5 labeled options (a–e, tuned to context; letter / letter+tweak / free-text answers all valid; if the user has no direction the agent states its own pick), and at the confirmation gate hesitation triggers 3–5 alternative directions before re-approval; cold start (the user's first message is the repo URL + an install/onboarding request) proceeds straight to preflight and onboarding
- SKILL.md: approval ask presents the run as one batch — batch size (N requests = 2N tracks), total estimated credits, current balance, estimated wall-clock time — with consent options (a approve and start / b change the plan / c cancel); after completion the agent reports actuals vs the estimate
- scripts/suno.js: usage ledger renamed `usage.jsonl` → `log.jsonl` — it is now the full request log (style / model / instrumental / durationReq / planFile / durationSec per request); renamed pre-release with zero external users, so no migration
SKILL.md: run file schemas documented (`status.json` field table; `report.md` fixed structure) alongside the existing `log.jsonl` schema
- SKILL.md: description trigger keywords expanded (study/sleep/cafe/work/video-channel BGM, jingles, theme songs; ja/en/zh example phrases)
- suno.js: `titles` subcommand — lists every used track title from `log.jsonl` and checks proposed names (normalized: case / underscores / punctuation ignored); the confirmation gate also warns automatically on reused titles
- SKILL.md: Lyrics (vocal mode) guidance — persona-based lyric theme, structure tags ([Verse] / [Chorus] / [Bridge] / [Outro]), the agent drafts lyrics for the user to edit, sensitive-word failure warning; sourced from pre-V6 community notes with an unverified-on-V6 caveat One option may be a vocal/lyrics variant and is routed to this section.
- READMEs + post: explainer deck link (GitHub Pages: /s/music-skill-deep-dive)
- READMEs + post: payment tiers ($5/$50/$500/$1,250; +5% / +10% bonus credits on $500 / $1,250), card & Apple Pay (no card-number disclosure), balance-based auto-recharge setting
- repo: published article now tracked (`docs/post/`; gitignore updated) — covers trigger-phrase examples, the a–e option interaction, batch-style approval (credits / balance / time / a-b-c), post-run actual reporting, and a cost comparison vs Suno plans (2026-09-13 rates: Premier $24 ≈ 800 tracks via KIE.AI vs 60 downloads)
- docs/slides: page images refreshed to the 16-page deck (new チャージと支払い page; cover / WhatIsSkill / WhatItDoes / Closing re-shot; WhatItDoes gains a スタイル記憶 card; unused p10/p13 exports removed). Deck layout: WhatItDoes switched to a 2×2 card grid with a new 自動ダウンロード＆命名 card, compact horizontal card design, Agenda in two columns; both decks (deep-dive / intro) aligned in wording and order

## Changed

- suno.js: `report.md` reworked into a Japanese track-level receipt — table `# | 曲名 | 長さ | ファイル | スタイル`, duration provenance (API-reported 約X分 → requested 要求X分（未確認） → —), spend in credits and ~USD at $0.005/credit, fixed memos (local backup / ~14-day platform retention / trim-longer-than-video / commercial-use), re-download URLs, engineer credits footer
- suno.js: at completion the full report is printed to stdout after `=== REPORT ===` so the agent relays it in chat — users see the result without opening the file (`--bg` runs: read `report.md` instead)
