# 0.5.3 — 2026-09-15 (CJK-safe track filenames)

Fix release — Japanese/Chinese track titles now survive into filenames instead of collapsing to `track.mp3`. Generation behavior unchanged. Update with `npx skills add GenKoKo/music-kie-suno-skill`.

## Fixed

- Track filenames preserve CJK titles (hiragana/katakana/kanji): `陽だまりランウェイ` keeps its name; the previous ASCII-only sanitizer stripped every non-ASCII character, so Japanese titles collapsed to `track` / `track_v2`
- ASCII title behavior is unchanged (40-char cap, whitespace → underscore, unsafe characters stripped)
- Internal: self-audit URL allowlist includes the README badge host (img.shields.io) so `scripts/self-audit.sh` passes on a clean checkout
