# 0.5.4 — 2026-09-15 (disk space pre-submit guard)

Safety release — batch downloads no longer fail mid-run for lack of disk space. Generation behavior unchanged. Update with `npx skills add GenKoKo/music-kie-suno-skill`.

## Added

- Disk space check before submission: the skill estimates download size (~10 MB per request, 5 MB per track) and aborts before any credits are spent if the output volume lacks room; a warning fires below a 3x margin
- Works with custom output roots (`OUTPUT_DIR_MUSIC_KIE_SUNO`) and resolves the output volume even when the target directory does not exist yet
